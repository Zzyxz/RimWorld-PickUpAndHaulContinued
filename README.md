# Pick Up and Haul - Continued

Colonists pick up several things into their inventory and haul them to a stockpile in one trip.

This is a continuation of [Pick Up and Haul](https://github.com/Mehni/PickUpAndHaul) by Mehni for RimWorld 1.6 and 1.7. It fixes bugs of the original, works with Combat Extended and keeps colonists' own supplies apart from what they haul. Use it instead of the original, not together with it.

## Requirements

- RimWorld 1.6 or 1.7
- [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)

## Building

Run `Source/Build.ps1`. It builds both game versions into `1.6/Assemblies` and `1.7/Assemblies`. The 1.7 build takes Harmony from the installed Harmony mod; adjust `HarmonyModDir` in `Source/PickUpAndHaul/PickUpAndHaul.csproj` if yours is somewhere else.
